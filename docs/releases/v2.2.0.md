# v2.2.0 - Iolana iolas

ΣEM moves to **Laravel 13 / PHP 8.4** and to the **GNU LGPL v3 or later** licence.

## Before you upgrade

- **PHP 8.4 is required.** Laravel 13 needs PHP 8.3 or later, and `composer.lock` is resolved
  for PHP 8.4 (several dependencies require PHP ≥ 8.4.1): `composer install` fails on an older
  PHP. Upgrade PHP on the server **before** pulling this release. The Docker image is now based
  on `php:8.4-fpm`.
- **No migration** in this release.
- **Dependencies**: `laravel/framework` 13, `spatie/laravel-backup` 10 (existing
  `config/backup.php` works as is), `doctrine/dbal` 4. No application code depends on the
  changed APIs; cache and session prefixes are unchanged, so users stay logged in.
- **Licence change**: releases up to v2.1.0 remain available under the MIT License. From
  v2.2.0, the project as a whole is distributed under the GNU LGPL v3 or later. See
  [NOTICE](NOTICE), [LICENSE](LICENSE) and [COPYING](COPYING). The Nest2Prod name and logos
  are trademarks, not covered by the code licence ([TRADEMARKS.md](TRADEMARKS.md)).

Upgrade as usual:

```bash
php artisan down
php artisan backup:run
git pull && composer install --no-dev -o && npm ci && npm run build
php artisan optimize:clear && php artisan config:cache && php artisan view:cache
php artisan queue:restart
php artisan up
```

## Security

No security advisory in this release.

## Fixes

- **Production install without dev dependencies**: `composer install --no-dev` no longer
  breaks the application boot. Laravel Telescope (a dev dependency) is only registered when it
  is installed.
- **Missing company logo**: if the logo file referenced in the database is missing, PDF and
  Factur-X documents, the customer portal and the public quote / order / delivery links are
  produced without the logo instead of failing; a warning is logged.
- **Workshop login mode**: choosing "Workshop" on the login screen now always opens the
  workshop, even when a desktop page had been requested before logging in.
- **PHP 8.4 deprecations** fixed (CSV import and export behave exactly as before).

## Changes

- The application version is shown on the login screens (it used to read "v1.19").
- New contribution guide ([CONTRIBUTING.md](CONTRIBUTING.md)): development setup, tests,
  commit conventions, licence of contributions.
- **Contributor License Agreement**: external contributors sign the [CLA](CLA.md) once, by
  commenting on their first pull request. They keep the copyright of their work.
